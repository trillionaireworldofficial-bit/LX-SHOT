# LX SHOT

A premium specialty coffee ecommerce experience built for LX SHOT with a quiet luxury visual language, centralized product data, and a responsive storefront.

## Stack
- React + Vite
- React Router
- CSS-driven premium UI

## Scripts
- npm install
- npm run dev
- npm run build

## Deployment
The repository is configured for GitHub Pages via the workflow in [.github/workflows/deploy-pages.yml](.github/workflows/deploy-pages.yml).
