LX SHOT Website Development Constitution 
Version 1.0 
This document defines the mandatory engineering, design, branding, UX, animation, 
performance, and quality standards for the LX SHOT website. 
Every AI agent contributing to this repository must follow these rules without exception. 
 
1. PROJECT MISSION 
You are not building a typical ecommerce website. 
You are building the official flagship website for LX SHOT, an ultra-premium specialty coffee 
brand centered on high-altitude Arabica, intentional energy, quiet luxury, and refined 
craftsmanship. All design and implementation decisions must reinforce these brand values as 
described in the Brand Story and Brand Tone Guide.  
 
2. NEVER CHANGE THE BRAND 
The AI must never: 
• redesign the logo  
• recolor the logo  
• stretch the logo  
• replace the logo  
• invent another brand identity  
• use placeholder logos  
• substitute generic coffee branding  
Every branded surface must display the authentic LX SHOT identity. 
 
3. PREMIUM DESIGN ONLY 
Everything must feel luxury. 
Not trendy. 
Not playful. 
Not colorful. 
Not cheap. 
Every page should feel like entering a premium boutique. 
 
4. NEVER USE CHEAP DESIGN PATTERNS 
Never use: 
  bright red buttons 
  neon colors 
  rounded cartoon buttons 
  oversized emojis 
  excessive gradients 
  random icons 
  clutter 
  generic ecommerce templates 
  cheap shadows 
  stock-style layouts 
 
5. UX PRINCIPLES 
Every interaction must feel intentional. 
Every animation must have purpose. 
Every page must breathe. 
Whitespace is part of the design. 
Luxury comes from restraint.

21. GITHUB WORKFLOW 
Before making major changes: 
1. Read all specification documents.  
2. Summarize the requested work.  
3. Identify dependencies.  
4. Build in small, reviewable commits.  
5. Keep commits focused and descriptive.  
6. Wait for approval before major structural refactors.  
 
22. QUALITY CHECK BEFORE EVERY COMMIT 
Before completing any task, verify: 
• No console errors.  
• No TypeScript errors.  
• No broken links.  
• No layout overflow.  
• No accessibility regressions.  
• Responsive behavior verified.  
• Performance impact considered.  
 
23. WHAT SUCCESS LOOKS LIKE 
When a visitor lands on lxshot.com, they should immediately feel: 
• This is a world-class specialty coffee brand.  
• The products appear crafted with exceptional care.  
• The experience is calm, luxurious, and trustworthy.  
• Purchasing feels simple and secure.  
• The website reflects the values of purity, precision, origin, and intentional energy 
established by LX SHOT.

engineering team before building a premium ecommerce website.
